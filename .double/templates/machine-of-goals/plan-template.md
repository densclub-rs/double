# Template: Preserved Plan Copy

## Preservation Contract

A documented realization normally links the actual approved main plan and
creates no local plan. Use this template as guidance only when the user chooses
to preserve previous realizations before an incompatible plan change. Follow the
workflow's Model Change and Succession rule before editing the main plan.

Copy the actual old plan to `plan.md` in each affected realization, without
overwriting existing files. Preserve its original id, metadata, substantive
content, stage and condition identifiers and anchors. Rebase relative links to
resolve from the copy, and verify content equivalence and links. A copy keeps
the source template and producer metadata: this guidance is not a mandate to
change provenance. Update each affected realization and stage record's links
and plan references to this local copy, preserving historical facts. A new
realization links the changed main plan. No copy is created for compatible
edits. Legacy frozen files retain their history unless separately authorized.
